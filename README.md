# Solinetz Winterthur — B2 Vokabel-Trainer

A browser-based vocabulary trainer for the **"Sicher! B2"** German course book, deployed under the name of **Solinetz Winterthur**, a Swiss organisation supporting refugee integration.

🇩🇪 German version: [README.de.md](README.de.md)

## Status

Code-wise, this is a mid-lineage snapshot of the B2 vocabulary trainer series — the underlying app is the same as `Sicher-Alll-Tag-und-Beruf-B2`. **[HEY-Bist-Du-Sicher-B2](https://github.com/Kutlu24/HEY-Bist-Du-Sicher-B2) is the current, most complete version of the app** (audio playback, larger word list). If this repository is still serving a live deployment for Solinetz Winterthur, keep it running as-is until that deployment is migrated; otherwise treat it as superseded.

## What it does

Plain HTML/CSS/vanilla JavaScript flashcard and quiz app over the vocabulary in `sicher.csv` / `modul1.json`. Runs entirely in the browser, no server or build step.
