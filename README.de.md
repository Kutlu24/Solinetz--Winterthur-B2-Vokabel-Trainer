# Solinetz Winterthur — B2 Vokabel-Trainer

Eine browserbasierte Vokabeltrainer-App für das Lehrbuch **„Sicher! B2"**, veröffentlicht unter dem Namen von **Solinetz Winterthur**, einer Schweizer Organisation zur Unterstützung der Integration von Geflüchteten.

🇬🇧 English version: [README.md](README.md)

## Status

Codeseitig ist dies ein mittlerer Stand innerhalb der Reihe von B2-Vokabeltrainern — die zugrunde liegende App ist dieselbe wie in `Sicher-Alll-Tag-und-Beruf-B2`. **[HEY-Bist-Du-Sicher-B2](https://github.com/Kutlu24/HEY-Bist-Du-Sicher-B2) ist die aktuelle, vollständigste Version der App** (Audio-Wiedergabe, größere Wortliste). Falls dieses Repository noch ein aktives Deployment für Solinetz Winterthur bedient, sollte es unverändert weiterlaufen, bis dieses Deployment migriert wird; andernfalls gilt es als abgelöst.

## Was die App macht

Karteikarten- und Quiz-App aus reinem HTML/CSS/Vanilla-JavaScript über den Wortschatz in `sicher.csv` / `modul1.json`. Läuft komplett im Browser, kein Server, kein Build-Prozess.
